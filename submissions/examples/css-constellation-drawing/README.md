# CSS Constellation Drawing

A lightweight constellation animation created entirely with HTML and CSS.

## Features

* Pure CSS animation
* No JavaScript
* Interactive hover effect
* Stars connected with animated lines
* Responsive design
* Keyboard focus support
* Reduced-motion support

## Files

* `demo.html` - Demo markup
* `style.css` - Constellation layout, stars, connections, and responsive styling

## Usage

Open `demo.html` in any modern browser.

Hover over the constellation to reveal the connected stars and lines. The constellation can also receive keyboard focus.

## Accessibility

The demo uses semantic HTML, an accessible section label, keyboard focus support, and respects `prefers-reduced-motion` for users who prefer reduced animation.
