# Gradient Shimmer Particle Effect

A smooth and performant **Gradient Shimmer** particle effect created using pure HTML and Vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Animated particles
- Gradient shimmer effect
- Smooth floating motion
- Dark/light mode compatibility
- Responsive design
- Hardware-friendly CSS animations
- Reduced-motion accessibility support
